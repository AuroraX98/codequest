# Ruby foundations 07–26

Twenty real concept lessons preserve the six existing starters. Visible teaching covers object/class inspection, numeric and truthiness rules, interpolation, aliasing, arrays/hashes/ranges, loop control, methods/keywords, blocks/procs/lambdas, captured bindings and safe navigation. Each has a changed-case understanding check with causal feedback, complete local source and a compact optional transfer.

`author.py` regenerates forty worked/changed fixtures plus lessons, units, exact support maps, terms and concept headings. `structure-validation.json` is not interpreter evidence. The actual shared Ruby 4.0.9 runtime receipts live in `../compiler-evidence`; independent semantic review is separate.

Review fixes make essentials visible in paragraph bodies, not only headings: only nil/false are false-like; Array literals create the shown entries; == tests equality rather than assignment. The missing-lambda-argument transfer intentionally raises ArgumentError. No Rails, YAML, FFI, downloaded gems or browser Ruby execution is needed or claimed.
